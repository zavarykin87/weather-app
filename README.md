Функционал приложения:

1. поле поиска позволяет ввести имя города и увидеть информацию о погоде в нем
2. блок отображения погоды показывает температуру и погодные условия в выбранном горооде
3. блок отображения карты для текущего города (с использованием Static Maps, интерактивность не требуется)
4. блок отображения истории поиска (последние 10 городов, которые смотрел пользователь, без повторов)
